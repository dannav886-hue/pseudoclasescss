01
CONCEPTO PRINCIPAL

¿Qué es una pseudoclase?

Una pseudoclase es una palabra clave de CSS que comienza con dos puntos (:). Permite aplicar estilos a un elemento cuando está en un estado, posición o condición determinada, sin agregar otra clase en HTML.

selector:pseudoclase { propiedad: valor; }

Ejemplo: button:hover cambia el aspecto de un botón cuando pasas el cursor sobre él.

02
ESTADOS DEL USUARIO

Pseudoclases de interacción

Reaccionan a las acciones de la persona que utiliza la página.

:hover

Al pasar el cursor

Se activa cuando el puntero está encima del elemento.

.boton:hover { background: ... }
:active

Al presionar

Se aplica mientras mantienes presionado un botón o enlace.

button:active { transform: ... }
:focus

Elemento enfocado

Se activa cuando un campo recibe el foco, por ejemplo al seleccionarlo con Tab.

input:focus { outline: ... }
:focus-visible

Foco visible

Muestra un indicador de foco cuando el navegador considera que debe verse, especialmente al usar teclado.

button:focus-visible { outline: ... }
:focus-within

Contenedor enfocado

Selecciona un contenedor cuando uno de sus elementos internos recibe el foco.

.caja:focus-within { ... }
:link · :visited

Estado de un enlace

:link selecciona enlaces no visitados y :visited los que el navegador registra como visitados.

Visita el resumen
a:link { ... }  a:visited { ... }
:target

Destino de un enlace

Selecciona el elemento cuyo id coincide con el fragmento de la dirección, por ejemplo #resumen.

Ir al ejemplo
¡Soy el destino :target!
#destino:target { ... }
03
VALIDACIÓN DE DATOS

Pseudoclases de formularios

Indican si un campo está vacío, marcado, habilitado o cumple las condiciones.

:valid · :invalid · :required

Prueba la validación

Escribe un correo válido y observa el borde. El campo es obligatorio.

Rojo: inválido. Verde: válido.
input:required:invalid { border-color: red; }
:checked

Opción marcada

Selecciona la casilla para activar el estilo.

input:checked { accent-color: ... }
:enabled · :disabled

Habilitado o deshabilitado

:enabled selecciona controles activos y :disabled los que no se pueden usar.

input:disabled { opacity: .5; }
:optional · :placeholder-shown

Campo opcional y vacío

:optional identifica campos no obligatorios; :placeholder-shown actúa mientras se ve el texto de ayuda.

input:placeholder-shown { ... }
:in-range · :out-of-range

Valores dentro o fuera del rango

Prueba un número entre 1 y 10 y luego escribe uno fuera del rango.

input:out-of-range { ... }
:read-only · :read-write

Solo lectura o editable

:read-only selecciona campos no editables; :read-write los que sí pueden modificarse.

input:read-only { background: ... }
:default · :indeterminate · :autofill

Estados especiales de controles

:default identifica el control predeterminado; :indeterminate un estado indeterminado; :autofill un campo autocompletado por el navegador.

Opción predeterminada
input:default { ... }

Pseudoclases estructurales

Seleccionan elementos según el lugar que ocupan dentro de su elemento padre.

:only-child · :only-of-type

Elemento único

:only-child identifica al único hijo; :only-of-type al único de su tipo entre hermanos.

Este elemento está solo.
.contenedor p:only-child { ... }
:empty

Elemento vacío

Selecciona elementos que no tienen contenido ni elementos hijos.

El espacio anterior es un elemento vacío.
div:empty { min-height: 20px; }

SELECTORES INTELIGENTES

Pseudoclases de relación y contexto

:not()

Excluir elementos

Selecciona los elementos que no coinciden con el selector indicado.

NormalExclúyemeNormal
span:not(.special) { ... }
:is()

Agrupar selectores

Aplica el mismo estilo a cualquiera de los selectores incluidos.

Título h4

Párrafo

:is(h4, p) { ... }
:where()

Agrupar sin especificidad

Funciona como :is(), pero su especificidad es cero y facilita sobrescribir estilos.

Texto agrupado
:where(.caja) { ... }
:has()

Seleccionar según contenido

Selecciona un contenedor si tiene un elemento que coincide con el selector.

.caja:has(input:checked) { ... }
:root

Elemento raíz

Selecciona la raíz del documento HTML. Se usa para declarar variables CSS.

:root { --color: teal; }
:root { --color-principal: ... }
:lang() · :dir()

Idioma y dirección

:lang(es) selecciona por idioma; :dir(ltr) o :dir(rtl) según la dirección del texto.

Contenido en español.

نص من اليمين إلى اليسار

p:lang(es) { ... }
:defined · :scope

Elementos definidos y ámbito

:defined selecciona elementos definidos; :scope representa el elemento de referencia de una consulta.

Se usan en consultas y componentes web.
:defined { ... }
:open · :modal · :fullscreen

Estados de interfaz

:open identifica elementos desplegables abiertos; :modal diálogos modales; :fullscreen elementos en pantalla completa.

PARA RECORDAR

Resumen de pseudoclases

GrupoEjemplos¿Para qué sirven?
Interacción:hover, :active, :focusResponden a acciones del usuario.
Formularios:checked, :valid, :disabledDetectan el estado de controles.
Estructurales:first-child, :nth-child()Seleccionan elementos por posición.
Relación:not(), :is(), :has()Seleccionan según condiciones.
Contexto:root, :lang(), :dir()Dependen del documento o contexto.

Idea clave

Las pseudoclases hacen que una página sea interactiva y dinámica. Cambian la apariencia de botones, enlaces, formularios y elementos según su estado o posición.
